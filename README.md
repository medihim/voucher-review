# voucher-review

이뻐(IPPEO) 2.0 관광기업 혁신바우처 과업 정합성 검수 페이지 (메디힘 내부 검수 자료)

- 열람: GitHub Pages 주소 또는 `index.html`을 브라우저로 열고 비밀번호를 입력한다.
- 비밀번호는 메디힘 담당자에게 별도로 받는다. 이 저장소와 커밋 메시지에는 비밀번호를 적지 않는다.
- 본문은 PBKDF2(SHA-256, 310,000회)로 만든 키로 AES-256-GCM 암호화되어 있다. 비밀번호 없이는 소스로도 내용을 볼 수 없다.
- 답변·증빙 입력값은 각자의 브라우저에만 저장된다. 공유는 페이지의 「답변 JSON 저장 / 불러오기」를 쓴다.

GitHub Pages 설정: Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
